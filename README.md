# TypeScript Types

A practical TypeScript learning repository focused on understanding TypeScript's type system through hands-on examples and exercises.

## 📌 About This Repository

This repository contains my practical exercises and learning progress while exploring TypeScript's powerful type system and advanced features.

The goal is to understand how TypeScript improves code safety, readability, and maintainability.

## 🚀 Topics Covered

- Basic Types
- Type Aliases
- Union Types
- Intersection Types
- Literal Types
- Type Assertions
- Type Narrowing
- Interfaces
- Generics
- Generic Constraints
- Generic Functions
- Generic Classes
- Promises with Generics
- Type Hierarchy

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Mezba-Morsalin/typescript-types.git
```

**2. Navigate to the project**

```bash
cd typescript-types
```

**3. Compile TypeScript**

```bash
tsc
```
